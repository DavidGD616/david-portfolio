01 / Documents & PDFs

ResuEase

A resume builder that brings editing, preview and export into one workflow.

ReactReact-PDFPDF.jsSupabase

The problem

Resume content needs to stay editable while the final document keeps a consistent layout. A preview is only useful if it matches the file you download.

The approach

Structured forms, reorderable sections and local autosave support the editing flow. Browser-side React-PDF generates the document; PDF.js renders the preview. Preview and download share the generated PDF artifact, replacing the previous Puppeteer-based export path.

What it demonstrates

A document workflow that connects user input to a downloadable output, with PDF generation handled locally in the browser. This is a personal project, not commissioned client work.

02 / API integration

SpotInsight

Making personal listening data easier to explore.

The approach

A React interface with an Express backend brings together Spotify listening data: top artists, tracks and recent plays. Playlist recommendations extend the experience from viewing information to acting on it.

What it demonstrates

Connecting an external API to a focused interface and turning several data views into a coherent user experience. This personal project runs locally; it is not presented as a live production service.
