## ✨ Features

- **Modern Design**: Clean, responsive layout built with TailwindCSS
- **Fast Performance**: Leveraging Astro's partial hydration for optimal loading speeds
- **SEO Optimized**: Includes sitemaps and robots.txt for better search engine visibility
- **Accessible**: Designed with web accessibility standards in mind
- **Dark/Light Mode**: Toggle between color schemes based on user preference
- **Mobile-First**: Fully responsive design for all device sizes

## 🚀 Getting Started

### Prerequisites

- Node.js 18 or higher
- npm or yarn package manager

### Installation & Development

1. Clone the repository:
   ```bash
   git clone https://github.com/DavidGD616/david-portfolio.git
   cd david-portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   # or
   yarn install
   ```

3. Start the development server:
   ```bash
   npm run dev
   # or
   yarn dev
   ```

4. Open your browser and visit `http://localhost:4321`

### Building for Production

```bash
npm run build
# or
yarn build
```

The built files will be in the `dist/` directory, ready to be deployed.
